1대1채팅 데스크톱 앱 (Windows)

[처음 실행]
1. 이 폴더를 오래 둘 곳(예: 문서 폴더)으로 옮긴 뒤 OneOnOneChat.exe를 실행하세요.
   - 폴더를 옮기면 '컴퓨터를 켜면 자동으로 실행'을 다시 켜야 합니다.
2. "Windows의 PC 보호" 창이 뜨면 '추가 정보' → '실행'을 누르세요.
   (서명되지 않은 개인 제작 프로그램이라 처음 한 번 뜹니다.)
3. 바탕화면 바로가기가 필요하면 OneOnOneChat.exe를 오른쪽 클릭 → '보내기' → '바탕 화면에 바로 가기 만들기'.

[브라우저에서 쓰던 대화 옮기기]
1. 브라우저로 연 1대1채팅.html에서 설정 → '전체 백업 저장'.
2. 이 앱에서 설정 → '백업 불러오기'로 그 파일을 고르세요.
   API 키는 백업에 들어가지 않으니 다시 입력하세요.

[창을 닫아도 계속 실행]
- 창의 X를 누르면 꺼지지 않고 작업 표시줄 오른쪽 아래 트레이(^ 안)에 숨습니다.
- 완전히 끄려면 트레이 아이콘을 오른쪽 클릭 → '종료'.
- 트레이 메뉴나 설정에서 '컴퓨터를 켜면 자동으로 실행'을 켤 수 있습니다.

[선톡]
- 설정 → 선톡에서 기능을 켜고, 캐릭터 화면 → '먼저 연락하기'에서 캐릭터별로 켜세요.
- 시간이 되면 윈도우 알림이 뜨고, 누르면 그 방이 열립니다.
- 알림이 안 오면 Windows 설정 → 시스템 → 알림에서 '1대1채팅'이 켜져 있는지,
  '방해 금지'가 꺼져 있는지 확인하세요.

[위젯]
- 대화 화면 위쪽 '위젯' 버튼 → 지금 방을 띄우거나(기억 이어짐), 위젯 전용 방을 만드세요(기억 따로).
- 캐릭터를 끌어서 옮기고, 한 번 누르면 말을 걸 수 있습니다. 오른쪽 클릭으로 크기·소리·닫기.
- 위젯 그림은 SD_기본.png, SD_기쁨.png처럼 SD_로 시작하는 파일을 씁니다 (배경이 투명한 PNG 권장).
  눈 감은 그림을 SD_깜빡.png로 올리면 가끔 눈을 깜빡입니다.

[데이터 위치]
- 대화와 설정은 이 컴퓨터의 %APPDATA%\1대1채팅 폴더에 저장됩니다.
  이 폴더를 지우거나 다른 컴퓨터로 옮길 때는 먼저 '전체 백업 저장'을 해 두세요.
