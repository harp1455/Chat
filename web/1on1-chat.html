1:1 채팅

아직 등록된 모습이 없습니다. 일러스트나 영상을 올리면 여기에 나타납니다.

누구와 이야기할까요

  1. API 키 넣기 설정에 Gemini API 키를 한 번만 넣으면 됩니다.
  2. 만들기 1:1로 톡 할 캐릭터나, 함께 이야기를 쓰는 스토리챗을 만듭니다.
  3. 대화하기 그림을 올리면 표정이 바뀌고, 목소리를 고르면 대사를 읽어 줍니다.

캐릭터

입력한 내용은 바로 저장됩니다.

🔒 제작자가 잠근 캐릭터입니다. 설정·지침·KB는 볼 수 없지만 대화에는 그대로 쓰입니다.

지식 (Knowledge Base)

최근 대화에 트리거 단어가 나오면 그 항목이 캐릭터 설정(메인 프롬프트) 바로 아래에 전달됩니다. ‘항상 적용’을 켜면 매번 전달됩니다. 한 번에 전달되는 항목 수는 설정에서 바꿉니다.

모습 (일러스트·영상)

주연 캐릭터의 그림은 ‘프롬프트 지시’ 탭의 각 인물 칸에 올리세요. 여기에는 배경이나 단역처럼 그 밖의 그림을 올립니다. 파일 이름이 이미지 코드가 됩니다(예: 배경.png, 카페_밤.png). ‘배경’은 뒤에 깔리는 그림입니다.

파일 이름이 이미지 코드가 됩니다. 한 명만 나오면 상황.png(예: 기본.png, 기쁨.png, 삐짐.webm), 여러 명이 나오는 스토리챗이면 이름_상황.png(예: 도윤_기본.png, 도윤_기쁨.png, 서준_당황.png)로 올리세요. SD_로 시작하는 그림(SD_기본.png 등)은 바탕화면 위젯에서만 쓰입니다. 밑줄(_) 앞의 이름으로 분류되고, 같은 코드에 여러 장을 올리면 그중에서 골라 씁니다(도윤_기쁨_2.png처럼 끝에 번호를 붙이면 됩니다). ‘기본’ 또는 ‘이름_기본’은 맞는 상황이 없을 때 대신 쓰이고, ‘배경’은 뒤에 깔리는 그림입니다.

목소리 (선택)

설명으로 새 목소리 만들기

만든 목소리는 내 API 키(구글 프로젝트)에 저장되며, 다른 사람의 키에서는 쓸 수 없습니다.

먼저 연락하기 (선톡)

메신저·마주 보고 대화 방식에서만 동작하고, 이 캐릭터의 가장 최근 방으로 보냅니다. 설정 화면에서 선톡 기능 전체를 켜야 합니다. 답이 없으면 최대 2번까지만 보내고, 대화 중(마지막 메시지 후 30분 이내)에는 보내지 않습니다.

내보내기와 삭제

내보낸 파일에는 설정과 모습이 들어 있고 대화 기록과 API 키는 들어 있지 않습니다. 받은 사람은 설정 화면의 ‘캐릭터 가져오기’로 불러옵니다.
잠금 파일은 암호화되어 있어, 받은 사람이 대화는 할 수 있지만 설정·지침·KB 내용은 볼 수 없습니다. 원하면 비밀번호도 걸 수 있습니다.
선톡을 알림으로 받아 보세요

알림을 허용하면 앱을 닫아 두어도 캐릭터의 메시지가 카톡처럼 도착합니다.

내 프로필

프로필은 상대가 알고 있는 ‘나’의 이름과 설정입니다. 여러 개 만들어 두고 방마다 골라 쓸 수 있습니다. 바꾸면 다음 응답부터 적용됩니다.

잠금 파일로 내보내기

받은 사람은 이 캐릭터와 대화할 수 있지만 설정·지침·KB·인물 설정은 볼 수도, 고칠 수도 없습니다. 이름, 그림, 플레이어 설정, 첫 인사, 목소리는 바꿀 수 있습니다.

대화할 때 설정은 받은 사람의 기기에서 구글 서버로 보내지므로, 기술을 아는 사람이 작정하고 들여다보는 것까지 막지는 못합니다. 그냥 열어 보거나 복사해 가는 것을 막는 용도입니다.

스토리챗

🔒 제작자가 잠근 스토리챗입니다. 프롬프트·KB·인물 설정은 볼 수 없지만 대화에는 그대로 쓰입니다.

입력한 내용은 바로 저장됩니다.

여섯 칸이 순서대로 합쳐져 메인 프롬프트가 됩니다. 비운 칸은 빠집니다. {{char}}는 제목, {{user}}는 플레이어 이름으로 바뀝니다.

1. 전체 문체 지침

시점과 시제, 문장 길이, 어휘, 분위기 등 글 전체의 결

2. 지문·대사 지침

지문 분량과 묘사 방식, 대사와 지문의 배치, 말투 표현

3. 장르·스토리·전개 지침

장르와 세계관, 줄거리, 전개 속도와 방향

4. 금지사항 지침

하지 말아야 할 표현, 전개, 행동

5. 주연 캐릭터

이름과 세부 설정을 적고 그림을 올리세요. 그림 파일 이름이 상황 코드가 됩니다(예: 기쁨.png → 이름_기쁨). ‘기본’은 맞는 상황이 없을 때 대신 쓰입니다.

6. 기타

HUD, 상태창, 주석 형식이나 그 밖의 규칙

크랙의 메인 프롬프트를 그대로 붙여 넣으세요. 이 칸 전체가 메인 프롬프트가 되고, KB는 그 아래에 들어갑니다. {{char}}·🄲는 제목, {{user}}·🅄는 플레이어 이름으로 바뀝니다.

인물 그림은 ‘이미지’ 탭에 이름_상황.png 형식의 파일 이름으로 올리면 이름별로 나뉩니다.

인물 이름과 목소리를 짝지어 두면, 본문에서 그 인물의 대사(따옴표 안)를 그 목소리로 읽습니다. 이름은 본문에 나오는 그대로 적으세요. 화면 위쪽 ‘소리 켜짐/꺼짐’으로 언제든 끄고 켤 수 있습니다.

지문

서술자 목소리를 정하면 지문까지 모두 음성으로 만들기 때문에 목소리 비용이 크게 늘어납니다. 누구의 대사인지 알 수 없는 대사도 서술자가 읽습니다.

      Vertex AI로 목소리 만들기 (선택)
      
    AI Studio 키는 목소리에 하루 요청 수 한도가 있습니다. 구글 클라우드의 Vertex AI(결제를 연결한 익스프레스 모드) 키를 넣으면 목소리만 Vertex로 보내 하루 한도 없이 쓸 수 있습니다. 대화는 계속 위의 Gemini API 키(AI Studio)로 보냅니다. Vertex 사용 금액은 구글 클라우드 결제로 청구됩니다.
    
      
      
    
        
        
      
    
      
      
    키, 목소리 모델, 직접 만든 목소리, 목소리 만들기 기능을 차례로 시험합니다.
    
      
      
      
      직접 만든 목소리는 만든 곳(AI Studio 또는 Vertex)에 저장됩니다. 앱이 목소리마다 Vertex에서 되는지 한 번 시험해 기억해 두고, 안 되는 목소리만 AI Studio로 읽습니다.

      지침
      
  
      
    
      모든 캐릭터에 공통으로 쓰이는 기본 지침입니다. 고친 내용은 바로 저장되고 다음 메시지부터 적용됩니다. 실제로 전달되는 전문은 대화 화면의 ‘기억’ 맨 아래에서 볼 수 있습니다.
      
    
    
    
      
      {{char}} 캐릭터 이름, {{user}} 내 이름 (크랙식 🄲, 🅄도 됩니다). 바로 뒤의 조사(과/와, 이/가, 은/는, 을/를)는 이름 받침에 맞게 자동으로 고쳐집니다.
      {{대화방식}} 캐릭터 화면에서 고른 대화 방식에 따라 아래 두 문장 중 하나가 들어갑니다.
      {{출력형식}} 등록한 표정과 목소리 설정에 맞춘 형식 안내가 자동으로 들어갑니다. 지우면 맨 뒤에 붙습니다. 이 안내가 없으면 표정과 목소리가 동작하지 않습니다.
      이 지침 뒤에는 캐릭터 설정, 추가 지침, 내 설정, 기억이 순서대로 자동으로 이어 붙습니다. 캐릭터 설정 안의 {{char}}, {{user}}도 이름으로 바뀝니다.
    
      
    
      
      
      
    
      
    
    
      
  
      
      



  
      위젯으로 띄우기
      
  
      
    
      지금 방의 대화와 기억을 그대로 이어 갑니다. 위젯에서 나눈 대화도 이 방에 쌓입니다.
      
    
      이 캐릭터의 새 방을 만들어 위젯에서 씁니다. 기억은 따로 쌓입니다.
      
    
      위젯 그림은 파일 이름이 SD_로 시작하는 그림을 씁니다(예: SD_기본.png, SD_기쁨.png, 눈 감은 SD_깜빡.png). 없으면 일반 그림을 씁니다. 배경이 투명한 PNG가 잘 어울립니다.
      
    
      캐릭터를 끌어서 옮기고, 한 번 누르면 말을 걸 수 있습니다. 오른쪽 클릭으로 크기, 소리, 닫기를 고릅니다.
